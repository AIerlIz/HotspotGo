# 热点快启 · HotspotGo

一键打开 Windows 移动热点。

单文件 exe，约 35 KB，无需安装运行时（Win10/11 自带 .NET Framework 4.8）。

## 用法

| 命令                        | 效果                                |
| ------------------------- | --------------------------------- |
| `HotspotGo.exe`           | 等电脑连上网，然后开启热点（默认最多等 90 秒）         |
| `HotspotGo.exe --wait 30` | 同上，最多等 30 秒（取值 0 - 86400，超范围按非法处理） |
| `HotspotGo.exe --any`     | 不等外网，直接用当前可用连接开启热点（电脑没网时也能开）      |
| `HotspotGo.exe --status`  | 查看状态（开关 / Wi-Fi 名 / 已连设备数），不做任何改动 |
| `HotspotGo.exe --off`     | 关闭热点                              |
| `HotspotGo.exe --help`    | 显示用法说明（`-h` / `-?` / `/?` 同义）     |

- 程序没有窗口，也没有控制台：**所有输出都写在 exe 同目录的 `log.txt`**（`--help` 的说明也是）
- `log.txt` 只追加、不轮转，随时可以删
- 开机自启：把 `HotspotGo.exe` 的快捷方式放进启动文件夹（`Win+R` 输入 `shell:startup`）
- 运行要求：64 位 Windows 10 / 11

## 退出码

计划任务 / 脚本据此判断结果：

| 退出码 | 含义                          |
| --- | --------------------------- |
| 0 | 成功，或本来就是目标状态                |
| 1 | 致命异常（`log.txt` 里有 `[FATAL]` 行，附完整堆栈） |
| 2 | 没有可用于共享的连接（等不到外网，或没有任何已连接的网卡） |
| 3 | 拿不到热点管理器（上游不能被共享，或系统组件异常）     |
| 4 | 开启热点失败                      |
| 5 | 命令行参数无法识别（**这种情况不会执行任何操作**）   |

参数无法识别时按失败退出，而不是忽略它继续跑：本工具不带参数就是“开热点”，
把 `--off` 敲成 `--pff` 会被当成默认动作，方向正好相反。

## 排障

先看 `log.txt`——它是唯一的输出通道。每次运行的日志以 `===== 启动` 开头、`===== 结束` 结尾，
中间每一步的结果（拿到哪条连接、连接等级、热点状态、开/关结果）都会记下来。

| 现象 | 先看什么 |
| --- | --- |
| 手机连上了却上不了网 | 日志里的“连接等级”不是 `InternetAccess`：上游没真正通外网，设备之间只能互访 |
| 一直开不起来（退出码 2） | “等待上游连接就绪”超时；或 `--any` 报“没有任何可用的连接” |
| 报“开启热点未成功”（退出码 4） | 日志里会有 `[错误] 调用 StartTetheringAsync ...`，那行写着系统给的原因 |
| 怀疑这台机器支不支持 | 先在「设置 → 网络和 Internet → 移动热点」里手动开一次；手动都开不了，API 更开不了 |

## 开发

```
dotnet build HotspotGo.slnx -c Release
dotnet test  HotspotGo.slnx -c Release
pwsh scripts/smoke-test.ps1            # 真跑一遍 exe（--status，只读）
pwsh scripts/smoke-test.ps1 -Toggle    # 额外真开一次再关掉（会改机器状态，默认不做）
```

单元测试只覆盖不依赖系统状态的部分（参数解析 / 反射通道 / 结果对象 / 日志器 / 退出码契约，
以及 Core 的编排判断——靠假实现替换掉 WinRT 操作）；真正调 WinRT 那条链路由冒烟测试跑真实 exe 兜。

发布：推一个 `v*` tag，`.github/workflows/release.yml` 会构建 → 测试 → 冒烟 → 把版本号按 tag
注入进 exe 并发布 Release。

图标由 `scripts/make-icon.py` 生成（改配色 / 形状就改那个脚本重跑，别直接编辑 `.ico`）。
